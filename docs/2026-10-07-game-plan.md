# Dragon Readers: game plan (2026-10-07)

A small Game Boy–style reading game for a beginning reader, themed on Tracey West's **Dragon Masters** books.
The player makes their own Dragon Master name, walks around Bracken Castle, and catches wild dragons by reading
the word that matches them.

## Decisions

| Topic | Decision |
|---|---|
| Reading level | Just starting. Mostly short sound-it-out words; a few tricky words in later areas. |
| Capture | Pick the matching word. 2 choices to start, 3 once he's doing well. |
| Wrong answer | Gentle retry: the wrong word fades, the right word is spoken, try again. No penalty. |
| Audio | Capture words are spoken only *after* he answers. Story dialogue has a tap-to-hear button. |
| Extras in v1 | Dragon Book (collection of caught dragons). |
| Player | Creates his own name. |
| Device | iPad, home-screen web app, works offline. |
| Hosting | GitHub Pages (public link, shareable with friends). |
| Art | Original pixel art drawn in code. No book illustrations. |

## Code layout

- `index.html`: screens (title, name, world)
- `css/style.css`: layout for iPad landscape and portrait
- `js/main.js`: game loop, screens, movement, dialogue
- `js/maps.js`: tile maps and NPCs
- `js/sprites.js`: pixel art drawn in code
- `js/input.js`: touch D-pad, A button, keyboard
- `js/storage.js`: save on device
- `js/speech.js`: spoken words via the iPad's built-in voice
